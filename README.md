A stdlib-only Python program that draws a newspaper front page summing up the world news of Tuesday 24 November 2026 — 37 verified stories led by Nvidia reinstating Jensen Huang as CEO, plus a markets strip — and writes it to `entry.png`. It hand-rolls its own 5x7 bitmap font and palette PNG encoder; no third-party packages, no network, deterministic output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
